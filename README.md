# OnyxTech Solutions Website

Production-ready static website for OnyxTech Solutions L.L.C.

## Included

- Responsive mobile navigation
- Local SEO metadata and canonical URL
- Open Graph metadata
- LocalBusiness structured data
- XML sitemap and robots.txt
- Service-focused lead-generation sections
- Starting-price estimator
- Service-request form
- Accessibility improvements including skip navigation and reduced-motion support
- Security-conscious remote-support messaging

## Deployment

The site expects `index.html` at the web root. Update the canonical URL, sitemap URL, and structured-data fields if the production domain changes.

## Important

The service form currently uses FormSubmit. Before production launch, verify the destination email, spam controls, privacy requirements, and confirmation behavior. For a full booking workflow, replace the form with a scheduling/backend solution.
